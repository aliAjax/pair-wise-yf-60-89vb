# 无障碍人工审计协作工作台

源提示词摘要：审计员记录问题、复现步骤、影响人群和严重程度，审核员判断重复或补充证据，开发人员提交修复，复测人员关闭或重新打开问题；所有核心流程可以用键盘完成，并正确管理焦点和错误提示。

## 技术栈

SolidStart、TypeScript、Park UI、Solid Router、TanStack Query、Solid Store、Modular Forms、Zod、Solid i18n primitives。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62025`

## 可用流程

- 创建审计问题，保存复现步骤、影响人群、证据和严重程度。
- 问题按待分诊、修复中、待复测、已关闭和重新打开流转。
- 将重复问题合并到主问题，保留来源关系（含合并时状态快照）和操作审计。
- 复测结论只对主问题生效：在来源问题上提交会转到主问题，来源只保存由主问题同步的影子结论；主问题状态一变，影子结论立即作废并断点重算。
- 概览的待复测、已关闭等统计只按主问题/独立问题计算，来源问题与挂起问题不重复计数。
- 两名审核员同时提交合并时先到先得：只有先到的合并关系生效，后到的提交被退回并给出说明；不允许产生链式合并。
- 合并可拆回：恢复来源问题合并前的状态与最后一次复测结论。
- v1 旧数据（只有一条主问题编号）升级时把链式合并压成一级并补齐来源关系；成环、目标缺失等分不完的问题挂起并记录原因；升级与重算均分批执行，中断后可从断点继续。
- 开发修复与复测结果分开记录，复测失败自动重新打开。
- 支持跳过导航、可见焦点、读屏提示、`N` 快捷键聚焦新建问题、`Ctrl+Enter` 提交。
- 数据保存在 localStorage（v2：`a11y-audit-v2`，自动从 v1 升级），Park UI preset 与 Ark UI 可访问交互原语参与界面实现。
